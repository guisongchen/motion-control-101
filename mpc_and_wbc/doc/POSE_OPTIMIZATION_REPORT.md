# 单腿站立初始位姿优化报告

> 项目：`week10_single_leg_stand` — Direct Single-Support WBC Benchmark  
> 日期：2026-04-22  
> 作者：Claude Code (辅助开发)

---

## 摘要

本文档总结了针对 G1 人形机器人单腿站立（single-leg stand）初始位姿的四组实验。实验依次尝试了**手动调参**、**离线静态优化**（两版）、以及**基于 WBC 仿真的优化**（Plan A）。核心发现是：

1. **静态优化**显著降低了重力矩和摩擦需求，但无法直接转化为动态滑移的改善。
2. **仿真优化**在短视距（1.0 s）内表现极佳，但在完整 3.0 s 验证中出现严重的**过拟合**——初期稳定，后期滑移累积爆炸。
3. **初始位姿与 WBC 控制器参数存在强耦合**。单独优化位姿而不调整控制器增益，存在明显的天花板。

---

## 1. 背景与动机

`direct_single_support.py` 中的单腿站立基准测试完全依赖手动调参（`DirectSingleSupportPoseConfig`）：

- `base_height = 0.72`
- `base_roll = 0.02`
- `support_pitch_delta = 0.02`
- 等 12 个参数

这些参数通过 `build_direct_pose()` 映射为 23 个关节角度，再由 WBC 闭环控制维持 3.0 s 站立。手动调参的 3.0 s 结果：

- 接触滑移 30.35 mm（阈值 20 mm，判定失败）
- CoP 误差 32.26 mm
- 摩擦比 0.236

目标是：**通过自动优化获得比手动调参更稳定的初始位姿**。

---

## 2. 实验方案

### 2.1 方案 A：手动调参（Hand-tuned Baseline）

**方法**：人工调节 12 个姿态参数，凭经验试错。  
**优点**：直观、快速。  
**缺点**：依赖经验，难以探索高维耦合空间；已知的最佳参数仍无法通过 success 阈值。

### 2.2 方案 B：离线静态优化 v1（纯软约束）

**文件**：`optimize_static_pose.py`（初版）  
**优化器**：`scipy.optimize.minimize` + SLSQP  
**变量**：基座 6D（位置 + RPY）+ 23 关节角度 = **29 维**  
**硬约束（等式）**：
- 支撑脚 body origin 位置固定（3 个）
- 支撑脚 body origin 姿态固定（3 个）

**边界约束**：
- 基座位置 ±0.2 m，RPY ±0.3 rad
- 各关节在 MuJoCo `jnt_range` 限位内

**目标函数（软惩罚）**：
- `w_tau * ||tau_gravity||^2` — 最小化关节重力矩
- `w_com * ||com_xy - support_xy||^2` — CoM 水平对齐支撑脚
- `w_margin * max(0, 0.02 - margin)^2` — 支撑多边形边界 margin
- `w_base_ori * (roll^2 + pitch^2)` — 基座姿态正则化
- `w_reg * ||joints - q_nominal||^2` — 与参考姿态偏差
- `w_swing_clearance * max(0, 0.02 - z_swing)^2` — 摆动脚离地

**权重**：`tau=1.0, com=100.0, margin=10.0, base_ori=1.0, reg=0.1, swing_clearance=1000.0`

### 2.3 方案 C：离线静态优化 v2（增加硬约束）

**文件**：`optimize_static_pose.py`（增强版）  
**在 v1 基础上增加不等式硬约束**：

| 约束 | 数量 | 说明 |
|---|---|---|
| CoM 在支撑多边形内 | 4 | `margin >= -15 mm`（因为 baseline 约 -25 mm，取中间值） |
| 摆动脚离地 | 1 | `z_swing >= 5 cm` |
| 关节力矩余量 | 23 | `|tau_i| <= 0.9 * tau_limit_i` |

**总约束**：6 个等式 + 28 个不等式。

### 2.4 方案 D：基于仿真的优化（Plan A）

**文件**：`optimize_pose_via_simulation.py`  
**优化器**：Nelder-Mead（局部搜索，无需梯度）  
**变量**：12 个**降维姿态参数**（与 `PoseConfig` 同维度），而非全 29D q 向量  
**内循环目标函数**：
- 运行 **1.0 s** WBC 仿真
- `cost = slip_mm + 0.3 * cop_mm + 20.0 * friction_ratio`
- 若中途倾倒，加 `1e4` 级惩罚

**边界处理**：手动 bounds + 评估时 clip 到合法区间。

**初始单纯形**：在 hand-tuned `x0` 附近，每个维度按 1%~5% 扰动构建。

**验证**：优化完成后，用最优解跑一次 **完整 3.0 s** 仿真，记录真实指标。

## 3. 实验结果

### 3.1 四组方案完整对比

| 指标 | A. 手动调参 | B. 静态 v1 | C. 静态 v2 | D. 仿真优化 |
|---|---|---|---|---|
| **优化维度** | 12（人工） | 29（SLSQP） | 29（SLSQP） | 12（Nelder-Mead） |
| **约束类型** | 无 | 6 eq + bounds | 6 eq + 28 ineq + bounds | bounds + clip |
| **迭代/评估次数** | — | 57 iter, 1737 eval | 53 iter, 1614 eval | 300 iter, 465 eval |
| **优化耗时** | — | ~3 s | ~3 s | **~1200 s**（20 min） |
| | | | | |
| **存活时间 [s]** | 3.000 | 3.000 | 3.000 | 3.000 |
| **基座高度 [m]** | 0.717 | **0.805** | 0.801 | 0.732 |
| **接触滑移 [mm]** | 30.35 | **26.72** | 31.28 | 32.65 |
| **体滑移 [mm]** | 30.60 | 31.77 | 32.76 | **22.88** |
| **CoP 误差 [mm]** | 32.26 | 34.04 | 34.27 | **12.61** |
| **摩擦比** | 0.236 | **0.058** | 0.068 | 0.226 |
| **切向力 [N]** | 192.4 | **123.4** | 143.6 | **49.0** |
| **Success** | False | False | False | False |

### 3.2 仿真优化的内循环 vs 全时长验证

方案 D 的独特之处在于存在**双重评估**：

| 指标 | 内循环（1.0 s） | 全时长验证（3.0 s） |
|---|---|---|
| 接触滑移 | **0.85 mm** | 32.65 mm |
| CoP 误差 | **1.93 mm** | 12.61 mm |
| 摩擦比 | **0.035** | 0.226 |

**现象**：1.0 s 内几乎完美稳定，但 3.0 s 后滑移累积至失败。这是典型的**短视距过拟合**。

---

## 4. 分析与讨论

### 4.1 静态优化为什么没能改善滑移？

静态优化的目标是**零速重力平衡**：最小化 `tau_gravity`、让 CoM 在支撑多边形上方。但 WBC 是一个**动态闭环系统**，其稳定性取决于：

1. 初始 Jacobian 条件数
2. 质量矩阵的分布
3. PD 增益与当前位姿的匹配程度
4. 接触力分布和摩擦锥约束

静态优化把基座抬高了约 8 cm，确实让机器人更直立、重力矩更小，但也改变了动力学特性。原有 hand-tuned 的 WBC 参数（`support_blend=0.705`, `com_kp=20` 等）是针对**略微屈膝、重心较低**的构型设计的，换到直立构型后，控制器不再是最优匹配。

### 4.2 仿真优化为什么过拟合？

优化器在 1.0 s 窗口内找到了一个**局部最优陷阱**：初期接触力分布均匀、CoP 几乎零误差，但 1.0 s 后，由于：

- 支撑脚接触力的微小不对称被 WBC 的积分项放大
- 基座 roll/pitch 的缓慢漂移未被 1.0 s 窗口捕获
- 摆动腿惯性引起的周期性扰动在更长时域上累积

导致滑移在 t=1.5~3.0 s 之间快速增长。

### 4.3 各方案的相对优劣

| 维度 | 最佳方案 | 说明 |
|---|---|---|
| 静态放松程度 | B（静态 v1） | 摩擦比最低 0.058，最省能量 |
| CoP 精度 | D（仿真优化） | 3.0 s CoP 误差仅 12.61 mm |
| 体滑移控制 | D（仿真优化） | 体滑移 22.88 mm，优于手动 30.60 mm |
| 切向力最小化 | D（仿真优化） | 49.0 N，远低于手动 192.4 N |
| 综合 contact slip | B（静态 v1） | 26.72 mm，为四组最低 |
| 计算效率 | B/C | 3 秒 vs 20 分钟 |

### 4.4 失败的根因

所有方案的 `success=False` 均因为 `contact_slip > 20 mm`。这说明：

> **在当前 WBC 参数固定的情况下，无论初始位姿如何优化，都无法将 3.0 s 滑移压到 20 mm 以下。**

瓶颈不在位姿，而在**控制器本身**（或控制器参数与位姿的失配）。

---

## 5. 结论

1. **静态优化有效改善了静态指标**（重力矩 ↓75%，摩擦需求 ↓35%），但对动态滑移的改善有限。
2. **仿真优化存在短视距陷阱**。用 1.0 s 内循环评估位姿质量，会严重低估长期滑移累积。若要用仿真优化，内循环必须覆盖完整 3.0 s。
3. **位姿与控制器参数强耦合**。单独优化位姿的天花板很低；真正突破 20 mm 滑移阈值，需要同时调整 WBC 参数（如 `support_blend`、`com_kp/kd`）。

---

## 6. 后续工作建议

### 6.1 短期：用完整 3.0 s 作为仿真优化的内循环

- 预计单次评估 2.5~3.0 s
- 300 次评估约需 **12~15 分钟**（仍在可接受范围）
- 可预期找到对 WBC 真正友好的位姿

### 6.2 中期：联合优化位姿 + WBC 关键参数

**分层方案**（推荐）：
1. 固定 WBC 参数，用 3.0 s 内循环优化位姿（12D）
2. 固定优化后的位姿，用 3.0 s 优化 3~5 个 WBC 参数（如 `support_blend`, `com_kp`, `com_kd`）
3. （可选）交替迭代 2~3 轮

### 6.3 长期：解析约束支撑脚姿态

当前所有方案都固定了支撑脚 body origin 的 6D 位姿。实际上，支撑脚与地面接触的 4 个 corner patch 并非严格共面。增加**4 个 corner 点同高**的等式约束（移除后尝试过但因不可行而放弃），可能进一步提升初始接触力均匀性。
